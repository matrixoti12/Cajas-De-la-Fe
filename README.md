# Cajas de la Fe 2026

Landing de la campaña de apadrinamiento de Iglesia Pacto y Bendición.

**Sitio:** https://matrixoti12.github.io/Cajas-De-la-Fe/

Página estática con HTML, CSS y JavaScript, sin instalación ni compilación.
GitHub Pages publica la rama `main`, desde la carpeta raíz `/`.
Los enlaces de imágenes y recursos son relativos para funcionar bajo la ruta del repositorio.

## Actualizar

- Contenido y fechas: `index.html`.
- Fichas: `app.js` y fotografías en `assets/`.
- WhatsApp y hoja CSV opcional: `config.js`.
- Apariencia y ajustes de celular: `styles.css`.

El sitio incluye 10 fichas; la meta de la campaña es de 20 niños.
Lucía tiene una ficha sin fotografía. Las tallas pendientes se indican en cada ficha.
Consultar por WhatsApp no reserva ni confirma un apadrinamiento.

Consulta [LEEME.md](LEEME.md) para la guía completa de configuración y operación.
